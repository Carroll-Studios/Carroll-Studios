## 🌙 Sobre a Carroll Studios

> Projeto acadêmico desenvolvido por estudantes do curso **Técnico em Informática** do **IFCE — Campus Maranguape**, para a disciplina de **Programação Orientada a Objetos**.

A Carroll Studios nasceu com uma ideia simples: cada projeto que lançamos é um "corpo celeste" dentro do nosso próprio sistema. O logo — uma lua crescente orbitada por um anel e uma estrela — representa isso: **vários satélites (projetos), um único centro gravitacional (a marca)**.
